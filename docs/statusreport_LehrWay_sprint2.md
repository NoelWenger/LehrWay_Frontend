### Geplante Arbeiten bis zum nächsten Bericht


- **Aufgabe 1: Zentrale Plesk Datenbank** <br>
Bis zum schluss muss die Zentrale Pleskdatenbank stehen und funktionieren. 
Wir oben erwähnt muss jeder User die veränderungen von anderen User automatisch bekommen.
Es soll keine manuelle synchronisierung notwendig sein, ausser evtl. beim Debuggen.


- **Aufgabe 2: Workflow Pipeline** <br>
Wie ebenfalls oben erwähnt ist die Workflow pipeline eienr der zwei grösseren Aufgaben die wir behandeln werden
(Zentrale Pleskdatenbank ist die andere).
Wir fokussieren uns auf die so schnell wie möglich.
Ebenfalls wird der start ins Modul M324 dies begünstigen.
Es soll automatisch Veränderungen gebuilden und auf Plesk hochladen. Das grösste Problem besteht bei der langsamen Infrastruktur von Plesk selbst.
Dies bewirkt, dass jegliche aktulisierungen sehr langsam gehostet werden.


- **Aufgabe 3: Zusätzliche Änderungen und Verbesserungsvorschläge von Herr Lagger** <br>
Jegliche Veränderungen, Verbesserungsvorschläge und Wünsche von Herrn Lagger werden ebenfalls agil im 3. Sprint berücksichtigt.
Dies könnte jegliche arbeiten bedeuten.
Meist sind dies kleinere CSS änderungen im Frontend. 
Gleichzeitig könnten kleine zukünftige unvorsehrbare Probleme/Bugs zu veränderungen führen.
Dies wird ebenfalls hier berücksichtigt.
Dazu gehören mögliche veränderungen bei Funktionen im Frontend
oder veränderungen im Backend.
